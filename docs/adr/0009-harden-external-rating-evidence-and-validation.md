# 保留外部评分证据、失败原因与真实样本验证

2026-11-16 的只读审查发现，动画电影类型、剧集路径、迷你剧季身份及上游响应差异可以让有分作品提前返回空；现有正常用例通过不能代表总体覆盖。延续 ADR-0008 的客户端获取与准确性优先边界：免费安装即用，不增加后端或个人 API key；单季不能用整剧或单集评分替代，无法确认映射时允许留空。

## 已确认

- Metacritic 有有效 Metascore 但缺少影评人数时仍展示分数，隐藏缺失人数；缺失和空字符串不能转为零。
- 保留外部评分获取结果的原因，提供默认关闭、按需复制的本地评分获取诊断；诊断包括作品标识、来源、处理阶段和结论，不上传数据，也不常驻 console 日志。
- 诊断入口使用现有油猴脚本菜单。用户手动开启后刷新页面重现问题，再复制本页报告；关闭后停止采集，不持久保存诊断历史。开关是否启用与诊断历史是不同的保留范围。
- Wikidata 已确认整剧但缺少季级映射时，允许读取该整剧在 RT／Metacritic 页面明确提供的季链接，再核验所属剧集与季号。不能猜季 URL，也不能仅因只有一季而把整剧与第一季等同。
- 官方规范重定向除了同站、canonical 和对象类型一致，还需要原作品的额外身份佐证；单季须核对原所属剧集及季号。证据不足时保留空缺，不由最终页面的自洽结构单独证明原、新对象相同。这项约束收紧 1.8.3 的 RT 重定向实现，并将同一准确性原则用于 Metacritic。
- Metacritic 与 RT 使用相同的评分快照期限：7 天内正常使用，7–30 天刷新失败时可保留已核验的旧评分并标注“旧评分”，超过 30 天隐藏。确认身份冲突时立即撤销，较晚完成的旧请求不能恢复评分或快照。保留获取日期供诊断使用，不新增“获取于某日”的整行文案。
- 固定评分样本回归必须通过，另做发布前联网评分抽查。网络或源站访问限制导致检查无法完成时，报告为未验证，交由用户决定是否发布；不把未验证算作通过或源站无评分。本轮继续不运行整套 E2E。
- 联网评分抽查报告在 PR 合并前供用户确认。已确认的实现回归必须修复；访问受限的未验证项目由用户决定是否接受。用户确认合并后，沿用版本号变更合入 master 即自动打 tag、创建 Release 的流程，不增加合并后的人工发布步骤。

## 设计不变量与验证范围

- 身份映射与评分页面分层验证：扩展电影类型及来源季链接覆盖，不能以降低身份核验要求换取命中率，也不为个别片名维护特例。
- 请求失败、API 错误响应与页面无法解析不是来源无评分或映射缺失；临时失败不能作为确定身份冲突而清除已核验快照。
- 真实样本覆盖普通电影、动画电影、整剧、后续季、首集 IMDb ID、迷你剧、页面别名，以及确实缺映射、无评分和身份冲突的负例。验证包括评分缺人数、真实零分、API 错误响应、重定向错误落点及旧请求晚到；固定样本的评分只代表采集时结果，不承诺实时值不变。

2026-11-16 用户已确认八项边界及整体设计，并授权整理、发布实现规格；本记录不表示实现已完成。原始页面中的可用身份字段及裁剪后的固定样本，应在实现规格中明确，不能把尚未核实的字段假设当作已有证据。

实现规格已发布为 [Issue #66：增强 RT 与 Metacritic 的作品核验、覆盖验证及本地诊断](https://github.com/ZlatanCN/douban-plus/issues/66)，标记为 `ready-for-agent`；主验收入口沿用已确认的 SubjectPageRuntime，只替换网络、时间及诊断菜单／复制等平台边界。

## 后续范围更正

2026-11-17 用户明确要求删除“评分诊断：开启”和“评分诊断：复制本页报告”两个菜单项。该决定覆盖上文的菜单／复制界面设计：运行时继续保留来源结果供自动回归与联网抽查观察，不提供诊断菜单、复制面板或诊断偏好持久化。
