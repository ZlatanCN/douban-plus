# Meta 双侧保留原生量表与同次快照

2026-11-17 用户确认将 Meta 扩展为 Metascore 与 User score 双侧评分，分别保留 0–100 与 0–10 量表，有效侧独立展示。八项问题与整体设计均已确认，完整讨论见[设计记录](../design/metacritic-user-score.md)；本记录不代表实现完成。

两侧来自同一已核验作品页面的一次 HTML 响应，作为同次快照替换；新响应明确缺分的侧不能由旧快照补回。代价是局部缺分时可见内容减少，但不需要两套侧级时间戳和缓存生命周期，也不会把不同获取时刻的数据伪装为同次结果。

部分解析失败时展示已确认有效侧，保留内部失败原因，但不写入成功快照、不更新旧快照时间；明确 TBD 属于正常单侧结果，可以保存。观众子区域身份冲突只拒绝该侧并禁止本次快照写入，页面／映射本身确认冲突则撤销整份 Meta 评分。两侧共同遵循既有 7／30 天期限和晚到请求撤销约束。

实现规格已发布为 [Issue #73](https://github.com/ZlatanCN/douban-plus/issues/73)，标记为 `ready-for-agent`，继续纳入 1.8.4 与 PR #72。
