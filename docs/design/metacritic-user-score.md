# Metacritic 双侧评分设计讨论

2026-11-17，用户要求增加 User score，并使用 grill-with-docs 确认设计。八项问题与整体方案均已由用户确认；本文件记录已接受的设计，产品代码尚未实施本次扩展。

## 已确认

- 保留原生量表：Metascore 为 0–100，User score 为 0–10。展示如 `90/100` 与 `9.1/10`，分母用小字，不互相换算或显示为百分比。
- 两侧独立存在，有一侧有效即可展示。TBD、尚未达到来源展示门槛与缺分均不数值化为零；来源明确的真实零分仍有效。
- 人数缺失不挡住分数，缺失人数行隐藏；观众人数应是该 User score 对应的评分票数，而非文字评论数。
- 使用类似 RT 的双列：左“影评人”、右“观众”，各侧人数文案只写“评价 N”；移除当前 Meta 横条及中文褒贬描述。
- 双侧属于同次获取的一份快照。新响应为 `91／TBD` 时用新 91 替换旧 `90／9.1`，不拼回旧观众侧。维持小于 7 天正常、7–30 天标“旧评分”、超过 30 天隐藏与未来时间戳无效；请求／解析失败不续期，确认身份冲突撤销两侧。
- 本次扩展继续纳入 `feat/v1.8.4` 和 PR #72，完成双侧回归并重新 build 后再准备合并。
- 同次响应中某侧结构异常／身份不足时先展示另一有效侧，保留内部错误原因，但不覆盖已成功保存的快照，也不更新其获取日期。明确 TBD 则属于正常缺分，可保存完整解析的单侧快照。
- 观众子区域指向整剧、其他作品或其他季时，仅拒绝该观众侧并按部分解析失败处理；已核验的当前对象 Metascore 可保留。页面本身或作品映射发生确认的身份冲突时，继续撤销整份 Meta 目标和两侧评分。
- 只从当前已核验来源页的一次 HTML 响应获取两侧，不新增观众 API 请求、页面 JavaScript 执行或文字评论抓取。

## 取数依据与准确性边界

- 当前 Meta 仅从已核验作品对象的 JSON-LD 读取 Metascore，数据契约与快照只保存这一侧。
- 2026-11-17 对电影《教父2》、迷你剧《切尔诺贝利》第一季和《掌舵少女》第一季直接读取公开原始 HTTP HTML，均返回 200；无需执行页面 JavaScript，即可读取原生观众评分区域及内嵌 `__NUXT_DATA__`。这不是实际脚本管理器验证，也不是对所有作品类型的覆盖承诺。
- 原生 User score 区域有明确的数值或 TBD 状态及评论链接。评论链接可携带具体季参数，必须与已核验页面身份对应。内嵌 summary 的 `reviewCount` 是总观众评分票数，文字评论组件的 `totalResults` 是另一统计。
- 《掌舵少女》第一季原始数据的用户 summary 为 `score=0, reviewCount=1`，原生页面却显示 `User score TBD` 和 `Available after 4 ratings`。必须遵守原站可展示状态；不能将内部默认零值视为真实已发布零分，也不把本样本的四票门槛硬编码为所有页面规则。
- 使用现有 DOMParser 直接解析同一响应的原生观众评分区域，明确绑定 User score 标签、当前对象评论链接和数值／TBD 状态。JSON-LD 继续只从正确作品节点读取 Metascore；不从全页任意 aggregateRating 或 userScore 取值，不引入 Nuxt 引用解码器。
- 沿用已确认的准确性优先边界：IMDb/豆瓣 ID 经 Wikidata 定位，核验电影／整剧／单季与父剧季号。新增观众侧不能绕过缺映射、身份冲突或来源限流；不恢复已删除的诊断菜单。
- 已有 Meta 图标继续打开实际核验页面；只显示有效侧时沿用 RT 的单侧展示方式，标签区分影评人和观众。无有效侧且明确都缺分才记来源无评分；存在未知／异常结构则保留解析失败原因。
- 新双侧快照使用新数据契约与命名空间，直接失效旧的单侧缓存，不迁移或兼容读取旧格式。已核验作品目标缓存与评分内容分离。

## 验收边界

- 沿用已确认的 SubjectPageRuntime 主入口，运行真实身份、映射、页面核验、双侧解析、缓存和展示，只替换 GM 网络与时间；运行时回调观察内部结果，不新增用户可见诊断入口。
- 固定原始响应片段记录来源、采集时间及粒度，覆盖电影、整剧、季、迷你剧与首集 IMDb 映射；《教父2》《切尔诺贝利》第一季作为已取得双侧原始 HTML 的基础样本。《掌舵少女》保留真实缺映射负例，单独对其来源 HTML 验证 TBD 门槛；不得为了正例在产品中硬编码映射。
- 覆盖双侧、合法单侧、缺人数、真实发布零分、TBD 内嵌零值、相关作品污染、错误季号／父剧、部分解析失败、7／30 天边界、未来时间、刷新不续期、身份冲突后旧请求晚到。
- 消融针对同一固定样本分别移除观众区身份核验、原站可展示状态核验、量表区分和快照写入保护，对应断言必须失败，恢复机制后通过。
- 回归、类型检查、lint 和 1.8.4 build；E2E 继续不运行。发布前联网抽查仍复用真实链路并区分通过、回归、未验证，不把此前用户接受的联网缺口当作本次新增路径已验证。
