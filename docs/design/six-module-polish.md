# 豆瓣 Plus 六模块打磨方案

**设计已确认，待实施。** 本方案记录六模块的实现范围、实施顺序和验收方式。

## 页面层级与共同规则

作品详情和人物页用海报、剧照、肖像与主标题构成各自的 Hero。作品图集、演职员、短评和影评总览使用紧凑页头，缩短从识别作品到看到首个内容项的距离。图集靠真实图片，演职员靠署名目录，短评靠完整正文，影评靠标题、摘要与阅读入口形成各自的视觉秩序。

- 四个总览页左上统一为「返回作品」。使用同一作品详情的真实链接，在当前标签页打开。上传图片、写短评和写影评各沿用所属页面的动作。
- 同一页的返回入口、标题和主体沿稳定的外边线组织。总览页优先复用已有字号、间距、色彩和焦点样式。标题自然换行，页头随内容增长。
- 各页面模块继续拥有自己的数据、呈现和样式。共用已有设计 token、通用链接样式和导航原语。只有稳定且无页面语义的重复才抽出共用，影评完整阅读继续由 `domains/review-reader` 提供。见 [ADR-0004](../adr/0004-page-modules-form-a-modular-monolith.md) 和 [ADR-0005](../adr/0005-review-reader-is-an-independent-domain-module.md)。
- 遵循既有 Sticky nav 的自动显示、始终显示、定位偏移和减弱动效行为。真实链接保留常规键盘与修饰键行为。见 [ADR-0007](../adr/0007-configurable-sticky-nav-visibility.md)。

## 各模块方案

### 作品详情 `subject`

- **评分条**。保留海报、背景剧照和作品主标题的层级，四个评分格继续使用原有的透明／遮罩呈现。豆瓣、IMDb、Meta、RT 的人数只展示数字与 RT 原有范围符号，移除重复「评价」前缀，缺失人数留空，并去掉 RT 单行／最大内容宽度补丁。评分来源、原生量表、双侧语义、人数及新旧状态继续遵循已核验评分契约。见 [ADR-0009](../adr/0009-harden-external-rating-evidence-and-validation.md) 和 [ADR-0010](../adr/0010-metacritic-native-scales-and-atomic-snapshots.md)。
- **短评预览**。桌面等宽双列，每一行的卡片等高，五条时末条靠左形成 `2 + 2 + 1`。日期与投票沿同一行底边对齐。保留最多四行正文及必要的展开入口。用一行和四行的正文做 A/B，检查短卡内部留白是否协调。窄屏保持单列，视觉顺序与豆瓣原顺序一致。

### 人物页 `personage`

- 保留肖像、姓名、资料和简介的身份层级。窄屏先呈现肖像、姓名与关键资料，简介落到身份区下方并占完整内容宽度。390px 样本的简介正文目前约宽 198px，目标是使用约 334px 的现有内容区。沿用三行摘要和原地展开，并在断点变化后按新宽度更新可展开状态。
- 核对无肖像、短简介、缺简介、长外文名和资料较多的样本。简介展开后继续按自然顺序进入下方分区。以现行「荣誉 → 近作 → 作品选 → 合作 → 图集」为分区顺序和导航名称，有内容的分区按该顺序呈现。见 [项目词汇表](../../CONTEXT.md#人物页)。

### 作品图集 `subject-all-photos`

- 收紧返回、片名、分类索引和首张图片之间的距离。将剧照、海报、壁纸及对应张数做成图集分类索引，仅呈现豆瓣提供的类别。单分类依然可跳到本页预览组。优先复用现有分组目标与固定导航定位行为。
- 保留左侧分组名、张数、原生「查看全部」及右侧保比例瀑布流。页头分类索引服务页内定位，分组的「查看全部」进入对应的豆瓣分类列表。沿用图集预览集、比例预留和挂载保护。

### 演职员 `subject-celebrities`

- 在与其他总览页相同的位置落下返回作品入口。保留角色分组、署名、肖像和代表作，缩短标题到第一组署名的距离。
- 用相同的可用宽度规则计算各组列轨。桌面单人的导演组占一个与演员同宽的列位，人数密集的组按相同列轨继续排列。长角色名允许两行，保留可读的完整名称。窄屏收为更少列，单列情况由可用宽度决定。

### 作品短评总览 `subject-comments`

- 保留无海报短评页头。压缩返回工具区、标题、短评状态索引到首条正文的间距。状态索引按实际得到的一、两或三项落列，当前选择与真实计数可见。
- 保留完整正文、短评共识刻度、原生短评分页导航和现有移动端短评浏览控制台。排序和评分按现有契约优先完整展示，仅在确实放不下时提供可见的横向溢出提示。状态切换、失败重试、登录及浏览器历史行为保持现有语义。

### 作品影评 / 剧评总览 `subject-reviews`

- 让压缩后的无海报页头更早交付影评阅读目录。保留左侧作者与右侧标题、摘要的阅读层级。提升「展开阅读」静止态的对比度和可发现性，沿用影评完整阅读入口。完整阅读、作者主页、投票、回应和豆瓣原文继续各有明确出口。打开完整影评后，滚动正文时顶部绿色强调线固定在阅读面板上缘。
- 移动端影评浏览控制台将排序和评分分成上下两组。用现有豆瓣选项文案，允许组内自然换行，使 320px 下也能看到所有有效选项。沿用既有导航、登录续接和选中状态。

## 实施顺序

1. **图集与短评总览**。先建立更紧凑的总览页首屏。图集完成分类索引，短评完成真实状态数排布。它们分别用图片和文本验证页头让出空间后的效果。
2. **演职员与影评总览**。统一返回入口与页头层级。演职员稳定署名列轨，影评提升阅读入口并调整窄屏筛选。
3. **作品详情与人物**。独立落实局部评分对比、短评卡片密度和人物窄屏简介。各改动通过所属模块的正常页面入口验收。

每一阶段都可单独预览、验收和提交。画面比较以同一实例、同一宽度和内容为基准，逐个关闭被评估的改动。例如评分只切换局部底面，短评卡片只切换等高，页头只切换留白。用对比图评估节奏和层级，以测量确认位置、宽度和可用性变化。
