# 豆瓣电影首页设计

**设计已确认，待实施。** 在 `feat/v1.9.0` 上为 `movie.douban.com/` 增加独立 userscript 页面模块。首屏服务选片，页头提供首页搜索和豆瓣原生导航。覆盖原首页内容，移除「合作联系」与「关注我们」。选电影、选剧集、排行榜等入口通往对应的豆瓣原生页面。

## 页面顺序

| 分区 | 呈现方式 |
| --- | --- |
| 正在热映 | 首屏用等宽的真实海报陈列作品，显示片名、豆瓣评分和「选座购票」。海报和片名打开作品详情，购票使用独立的原生链接。「全部正在热映」和「即将上映」保留豆瓣原入口。 |
| 一周口碑榜 | 按豆瓣名次对齐展示名次和片名，保留「更多榜单」和附近的「豆瓣电影评分八问」。 |
| 热门片单 | 用标题列表呈现豆瓣片单，保留原有推荐数和片单链接。 |
| 热门推荐 | 用豆瓣提供的图片、标题和摘要展现专题，保留年度专题的原有入口。 |
| 最受欢迎的影评 | 展示影评标题、作者、关联作品和原生摘要，保留全文、更多热门影评和新片影评链接。 |

各区沿同一组左右边线对齐。沿用豆瓣 Plus 的深色底和系统中文字体，绿色用于交互，金色用于评分。海报使用现有圆角与细内描边。悬停反馈只用于支持悬停的设备，键盘操作即时响应，并尊重减弱动效偏好。

## 首页搜索

桌面页头直接显示搜索框，手机让搜索框独占一行。候选参考作品切换器的缩略图、名称与辨识信息，作品年份和原名以现有数据为准。影人候选使用可验证的豆瓣直达链接。

按 `/` 聚焦，按上下键选择候选，回车打开选中项。`Esc` 收起候选并保留输入。中文输入法组词期间继续由输入法接收按键。未选候选时，回车在当前标签页提交豆瓣完整搜索，覆盖电影、电视剧、综艺和影人。候选为空或加载失败时，完整搜索仍可提交。

## 热映分页

每组四部，桌面四列，手机两列。按豆瓣原顺序逐组展示首页提供的全部热映作品。长片名自然换行，评分和购票始终可见，原生无评分时显示「暂无评分」。

「上一组」「下一组」和组数放在标题附近。换组即时，焦点留在原控件。翻组仅更新当前首页历史条目的组号，浏览器后退仍在网页之间导航。从作品详情或搜索结果返回首页时按组号恢复。豆瓣更新列表后仍沿用原组号，超出范围时显示最后一组。新开的首页从第 1 组开始。

## 首页挂载保护

先保留原生首页，完成原生内容和有效入口的提取校验后一次性切换。已确认豆瓣本次没有提供的区块可省略。单条作品缺海报时保留片名和链接，用等比例占位保持布局。若解析失败会丢失原生已有条目或有效入口，或用户已在原生搜索框输入，本次继续显示原生首页。

## 验收

- 在桌面与窄屏打开站点根路径，核对分区顺序、海报布局、完整内容和原生链接。
- 用长片名、暂无评分和末组不足四部的样本检查海报、评分、购票与分页。从原生作品详情或搜索结果后退应恢复原组号，在首页翻组后按浏览器后退应回上一个网页。若热映列表缩短至原组号之外，应显示末组。
- 用同名作品和影人查询验证候选、完整搜索和当前标签页行为。检查中文输入法、键盘焦点、候选失败和减弱动效状态。
- 检查原生区块确实为空、单条缺海报、已有条目或链接提取失败，以及原生搜索已输入这几种情况的挂载结果。
